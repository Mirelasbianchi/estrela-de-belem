# A Estrela de Belém

Jogo 3D de Natal para navegador (celular e computador) que conta a história de Jesus, da Anunciação ao Nascimento, em 7 capítulos, guiado por uma anjinha mensageira.

- `index.html`: site de divulgação (em construção)
- `jogo/`: o jogo (Three.js, sem instalação, sem servidor)

## Rodar localmente

```bash
python serve.py
```

Depois abra http://localhost:8123/jogo/
